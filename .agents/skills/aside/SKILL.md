# Aside

共通規約は `AGENTS.md` と `.codex/rules/index.md`、作業に該当するルールを読む。
入力はスキル名に続くユーザーの依頼文として解釈する。Claude用の引数展開には依存しない。
Claude側の設定・資源は変更しない。回答と成果物は日本語にする。

元の `.claude/commands/aside.md` のCodex版。
進行中の目的・直前の工程・次の操作を控えてから質問に答える。
必要なコードや資料は読み取りだけで確認し、この質問への回答のためにファイルを変更しない。
結論を先に短く答え、コードについてはファイルと行を示す。
回答は進行中ならcommentaryで送り、「元の作業：…」を添え、同じ工程から続行する。
作業がなければ通常の回答として終える。

質問がなければ質問内容を確認する。曖昧なら必要な点を1つだけ確認する。
明確な作業変更指示は最新の指示として反映する。情報質問か方向転換か曖昧なら、
推奨案と理由を示して確認し、影響を受けない作業を続ける。
問題を発見した場合は根拠と影響を伝え、既存の承認内で修正できれば元タスクで対処する。
新たな判断が必要な場合だけ確認する。横からの質問が続いた場合も元タスクの状態を保つ。
