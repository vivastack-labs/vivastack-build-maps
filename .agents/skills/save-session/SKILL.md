# Save Session

共通規約は `AGENTS.md` と `.codex/rules/index.md`、作業に該当するルールを読む。
入力はスキル名に続くユーザーの依頼文として解釈する。Claude用の引数展開には依存しない。
Claude側の設定・資源は変更しない。回答と成果物は日本語にする。

元の `.claude/commands/save-session.md` のCodex版。
会話、差分（未追跡を含む）、現在のブランチ・worktree、実行済み検査結果を確認する。
未実行の検査を通過扱いにせず、失敗した方法と理由を残す。秘密の値や不要な個人情報は保存しない。

Markdownを一時ファイルに用意し、次で保存する（リポジトリルートから実行）。

```bash
python3 .agents/skills/sessions/scripts/session_store.py save < <一時Markdownファイル>
```

既定の保存先はこのworktreeの `.codex/sessions/`。毎回、実際の日付と一意なIDを持つ
新しいファイルを作る。既存記録は上書きしない。ユーザーが保存先を指定した場合だけ
`--store <ディレクトリ>` をサブコマンドの前に指定する。sandboxの許可範囲に従う。

記録には次を含め、ない項目には「なし」や「未確認」と書く。

- 日付、開始時刻（分かる範囲）、最終更新時刻
- `**Project:**`、`**Branch:**`、`**Worktree:**`、`**Topic:**` のメタデータ
- 作っているもの・目的・依頼範囲
- 成功したことと根拠（コマンド、結果、対象差分）
- 失敗した方法と具体的な原因、まだ試していない方法
- 変更ファイルと現在の状態（完了・作業中・未着手・失敗）
- 決定事項と理由、未解決の問題・判断事項
- 再開時の最初の具体的な操作、必要な環境情報

保存先の絶対パスと秘密を除いた記録本文を示し、訂正は反映する。
保存のためだけに終了確認を強制しない。作業途中の保存依頼なら元タスクへ戻る。
これは手動の引き継ぎ記録であり、Codex内部の会話履歴やhooks活動記録の復元ではない。
