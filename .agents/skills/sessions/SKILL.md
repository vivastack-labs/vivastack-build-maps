# Sessions

共通規約は `AGENTS.md` と `.codex/rules/index.md`、作業に該当するルールを読む。
入力はスキル名に続くユーザーの依頼文として解釈する。Claude用の引数展開には依存しない。
Claude側の設定・資源は変更しない。回答と成果物は日本語にする。

元の `.claude/commands/sessions.md` のCodex版。
Claudeプラグインやグローバル履歴には依存せず、既定でこのworktreeの `.codex/sessions/` を扱う。
これは手動保存した引き継ぎ記録の管理であり、Codex内部の履歴・会話IDは操作しない。

リポジトリルートから `python3 .agents/skills/sessions/scripts/session_store.py` に次を渡す。

| 依頼 | サブコマンド |
| --- | --- |
| 引数なし・一覧 | `list`（既定50件、更新順） |
| 絞り込み・ページ送り | `list --limit 10 --offset 10 --date YYYY-MM-DD --search <ID文字列>`（必要な指定だけ） |
| 内容 | `load <ID・日付・別名>` |
| 詳細 | `info <ID・日付・別名>` |
| 別名の設定 | `alias <ID・日付> <名前>` |
| 別名の削除 | `unalias <名前>`（依頼の `alias --remove` もここへ変換） |
| 別名の一覧 | `aliases` |
| ヘルプ | `--help` または対象サブコマンドの `--help` |

保存先を明示された場合だけ `--store <ディレクトリ>` をサブコマンド前に付ける。
一覧にはID・日付・更新時刻・Project・Branch・Worktree・該当する別名を表示する。
infoは上記に加えファイル名・絶対パス・行数・サイズ・チェックボックスのタスク総数/完了数/作業中数を表示する。
loadは本文を表示し、再開を依頼されたら `$resume-session` の読み取り・照合手順を使う。
ユーザー入力は構造化した引数かシェル用に適切に引用し、コードへ埋め込まない。

IDが曖昧なら選ばず長いIDを求める。日付は同日の最新を選ぶ。
別名は英数字・ハイフン・下線のみ。既存別名の付け替えは対象を説明する。
記録がなくても読み取りでディレクトリを作らない。破損した別名データを上書きしない。
保存先と親のシンボリックリンク、Claude側を指す保存先は拒否する。
別名更新は排他的ロックを使う。同時更新は非0で失敗し、成功した更新を消さない。
異常終了で `.aliases.lock` が残ったら、他の更新処理が終了したことを確認してから除去する。
所有者が不明なら削除せず、更新処理の終了確認後の再試行を推奨する（理由：更新の喪失を防ぐため）。
CLIはJSONを返し、不正入力は非0で失敗する。成功したと偽らない。
