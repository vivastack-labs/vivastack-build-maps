# Update Documentation

共通規約は `AGENTS.md` と `.codex/rules/index.md`、作業に該当するルールを読む。
入力はスキル名に続くユーザーの依頼文として解釈する。Claude用の引数展開には依存しない。
Claude側の設定・資源は変更しない。回答と成果物は日本語にする。

元の `.claude/commands/update-docs.md` のCodex版。
実装を正として、依頼範囲の文書だけを更新する。

1. package.jsonのscripts、公開export、スキーマ、ルート、存在する環境変数のテンプレートを調べる。
   実在しないAPI・DB・Docker構成は作らない。秘密の値を読み取って転載しない。
2. コマンドの完全な参照は `AGENTS.md`、入口のコマンドだけ `README.md` に反映する。
   Node.jsは.nvmrc、パッケージ管理はpnpm、デプロイはCIのみという規約を保つ。
3. 環境変数は用途・必須か・形式を記載し、ダミーの例を使う。
   CONTRIBUTING・RUNBOOK等が既にあれば該当箇所を照合する。
   作成が明示されていなければ新しい文書を増やさない。
4. `docs/architecture/`、設計書・タスク定義との整合を確認し、変更範囲に必要なものを更新する。
   手書きの説明は保つ。生成領域は既存マーカーに従い、追加するときは
   `<!-- AUTO-GENERATED -->` と終了マーカーで範囲を明示する。
5. Gitの更新日と関連実装の変更から、90日以上未更新の文書を調べる。
   古い日付だけで誤りとはせず、内容の不一致を根拠つきで報告する。
6. Markdownとリンク・コマンドの存在を検証し、更新・変更不要・要確認をファイル別に報告する。
   未実行のコマンドは実行済みにしない。検査設定やClaude設定は変えない。
