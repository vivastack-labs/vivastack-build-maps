# アーキテクチャ：画面の枠組み・多言語・モード

エージェント向けの実装メモ（`AGENTS.md` の「アーキテクチャ」から分けた）。この範囲のコード・テストを変える前に読み、変えたら更新する。「上の〜」「下の〜」で指す節は、同じフォルダのほかのファイルにあることがある。

- ふりがなの記法 `{漢字|よみ}`（7.2）：`src/lib/ruby.ts` の `parseRuby`（誤りがあれば例外）・`checkRuby`（誤りと警告の一覧）・`plainText`（読みを除く）と、`<ruby>` を描く `src/components/RubyText.tsx`（`<rt>` は `aria-hidden="true"`。読みが名前に入って二重に読まれるのと、WCAG 2.5.3 の違反を防ぐ。T4-03）。`dangerouslySetInnerHTML` は使わない。
- UI文言の辞書（6.2 D28）：`src/i18n/ja.ts`（基準）・`en.ts`・`zh.ts`。`getMessages(lang)`（`src/i18n/messages.ts`）で引く。文言を足すときは `ja.ts` に書くと、`en.ts`・`zh.ts`（`satisfies Messages`）はキーが足りなければ typecheck で落ちる。日本語はふりがなの記法つきで書き、`RubyText` で描く（`aria-label` など属性は `plainText()` で読みを除く）。こども向け・おとな向けで言い方を変える文は `{ kids, adult }` にして、`ModeText` で両方を出す（表示の切替は CSS。下の「モード・ふりがな」）。数は `formatNumber(lang, value)`。フォントは `app/globals.css` の `--font-sans` を `:root:lang()` で言語ごとに切り替える（D27）。
- 画面の枠組み（4.11.7、T2-03。T4-05 で変更）：`Header`・`Footer` は `app/[lang]/layout.tsx` ではなく、各ページが `PageFrame`（`src/components/`。`lang` と `page`〔`PAGES` の `home`・`about`・`privacy`〕を受け取り、`Header`・本体・`Footer` を並べる）で置く。ルートレイアウトは子のページを知らないので、`Header` の h1 の出し分け（トップ＝サイト名が h1、ほかのページ＝サイト名はトップへのリンクで、ページの題名が `<main>` の中の h1）・言語切替の行き先（同じページ）・`Footer` の `aria-current` を、ページが渡す `page` で決める。`<title>` はレイアウトの `generateMetadata`（ほかのページは「題名 | サイト名」で上書きする）。地図・カード・さくいん（`MapArea`・`CardArea`・`IndexArea`）は `app/[lang]/page.tsx` に置く。各領域は `data-area` で見分け、1024px以上で地図とカードが2列、それより狭いと1列。ランドマークは `header`・`main`・`footer` の3つだけにする（領域の `section` に `aria-label` を付けない）。
- `Footer` のトップページ表示（F-SRC-04、D48）は説明ページへの2つのリンク。地図データの出典と AI の利用の文は `page` が `about` または `privacy` のときに描画する。`tests/e2e/footer.spec.ts` でトップページから出典のある説明ページに移動できることを確かめる。
- モード・ふりがな（T3-05。F-MODE-01〜04、6.6 (3)、D23・D37、4.11.5）：
  - 状態は `<html data-mode="kids|adult" data-ruby="on|off">` だけが持つ。`app/[lang]/layout.tsx` が言語ごとの既定値（`src/features/mode/settings.ts` の `DEFAULT_DISPLAY`。D37：ja＝kids・on、en・zh＝adult・on）を書き、`<head>` の初期化スクリプト（`src/features/mode/initScript.ts` の `MODE_INIT_SCRIPT`。500バイト未満の固定の文字列。T4-01 でハッシュを CSP に入れる）が、最初の描画の前に localStorage の `maps.mode`・`maps.ruby` で上書きする。正しくない値は無視し、localStorage が例外を投げても何もしない。同じスクリプトが、URL のハッシュが `#pref-01`〜`#pref-47`（`prefFromHash` と同じ形）なら `<html data-hash-pref="NN">` に県コードを書き、そうでなければ消す（`hashchange` でも。localStorage の例外とは別。T4-04。**この属性は、ハイドレーションの前の CSS の規則と `CardDetails` のマウントの時点の予約だけが使う**。ハイドレーションの後は、`HashSync` の `replaceState` が `hashchange` を起こさないので古い値のまま残る。後から「今のハッシュの県」として読まない。`:target` を待たずにカードを表示するため。上の「県のカード」・「カードの内容の JSON」の CLS の項）。グローバルの変数を増やさないよう関数で包み、現在 380 バイト。`<html>` に `suppressHydrationWarning`。`dangerouslySetInnerHTML` を使うのはこのスクリプトだけ（固定の定数）。localStorage のキーは言語で分けず、ボタンを押したときだけ保存する（`applySetting`：属性を書いてから保存し、保存の例外は飲み込む）。
  - 出し分けは CSS だけ（`app/globals.css`。レイヤーの外なので Tailwind のユーティリティより強い）：`:root[data-mode='kids'] .adult`・`:root[data-mode='adult'] .kids` を `display: none`（読み上げ・`aria-live`・ボタンの名前からも除く。`visibility`・`opacity` は使わない）、`:root[data-ruby='off'] rt` を `display: none`。`@custom-variant kids`・`adult`・`ruby-off` で、`<html>` の属性から見た目のバリアントを使える。`ModeText` の `.kids`・`.adult` に `display` を上書きするクラスを付けない。
  - 切替のボタン：`DisplayToggle`（クライアント）を `Header` のサイト名の横に置く（文言は辞書の `display`。モードによらず同じ文言）。モードは「こども」「おとな」の2つのボタン（`role="group"`）、ふりがなは1つのトグル（ja のページだけ）。`aria-pressed` は `useSyncExternalStore` で `<html>` の属性を読み（`MutationObserver` ＋ ボタンを押した直後の `notify`）、押した見た目は `kids:`・`adult:`・`ruby-off:` のバリアントで付ける（ハイドレーションの前から正しい。Tailwind が拾えるよう、クラス名は組み立てずに書く）。JavaScript がないときは `noscript:hidden`（`@media (scripting: none)`）で隠す。
  - 言語の切替（T3-07）を `<Link>` のソフトナビゲーションにすると、React が `<html>` の属性を既定値に書き戻して保存した値が消える。言語の切替は全体の読み込み（`<a>`）にしてある（下の「言語の切替とハッシュ」）。
  - E2E は `tests/e2e/mode.spec.ts`（最初の描画の値は `addInitScript` の `MutationObserver` で `<body>` が入った時点を記録する。localStorage の拒否は `window.localStorage` の getter を例外にする）。スクリーンショットは `ja-card-adult-ruby-off`。
- 言語の切替とハッシュ（T3-07。F-I18N-03、4.11.2、D8）：`Header` に `LangSwitch`（サーバー）。`<ul data-lang-switch aria-label>` に、ふつうの `<a data-lang-link hreflang lang>`（`next/link` は使わない。ソフトナビゲーションだと `<html data-mode data-ruby>` が既定値に書き戻される〔T3-05〕）。今の言語に `aria-current="page"`。言語の名前は `LANG_NAMES`（`src/i18n/lang.ts`。その言語で書き、辞書に入れない）。`<nav>` は使わない（ランドマークは3つだけ）。
  - `HashSync`（`src/components/`、クライアント。DOM を出さない。`page.tsx` の `MapStateProvider` の中）：開いたとき `useLayoutEffect` で `prefFromHash(location.hash)`（`src/features/map/hash.ts`。`#pref-NN` の NN が県コードの範囲のときだけ。それ以外は null）の県を `restore`（固定だけ。最大化しない。正しくないハッシュは無視で、ハッシュも消さない）。復元が終わってから、固定が変わるたびに `history.replaceState(history.state, '', path + search + hash)` でハッシュを合わせ（履歴は増えない。固定を外すとハッシュを消す。正しくないハッシュは開いたときに消さない。URL は `new URL(location.href)` の `hash` に書いて渡す。`history.state` は Next.js 16 がルーターとの同期に使うのでそのまま渡す）、`a[data-lang-link]`（属性名は `LANG_LINK_ATTRIBUTE`、パスは `langPath(lang)`。`src/i18n/lang.ts`）の `href` に同じハッシュを付ける（属性だけを書く。6.6 (2)。値が言語でないリンクと、今の言語〔`aria-current="page"`〕のリンクは書き換えない）。
  - `CardSheet`（`useSheetDom`）：利用者の操作（`document` の捕捉の `pointerdown`・`keydown`・`click`）の前に開いたとき（＝ハッシュの復元）は、フォーカスを移さない（WCAG 3.2.1）。768px 未満では、パネルを全部見える状態（`full`）で開く（描画の中で `expanded` を true にする。ハイドレーションの前の `:target` の見た目と同じで、縮まない。CLS）。操作の有無は `useHasInteracted`（状態）。利用者が操作してから固定したときは、今までどおり `peek`。
  - `<head>`：`app/[lang]/layout.tsx` の `generateMetadata` が `alternates: alternateUrls(lang)`（`src/lib/site.ts`。`SITE_URL = https://maps.vivastack-dev.workers.dev`）を返す。`canonical` はそのページ、`hreflang` は ja・en・zh-Hans・x-default（→ ja）。プレビュー用のビルドも本番の URL（`noindex` が付く）。
  - E2E は `tests/e2e/lang-switch.spec.ts`。スクリーンショットは `en-from-ja-pinned`。
- 「このサイトについて」・プライバシーポリシー（T4-05。F-SRC-04、8.3、5.6、R10、D43）：`app/[lang]/about/page.tsx`・`privacy/page.tsx`（サーバー。`PageFrame` の中の `<main>` に `AboutContent`・`PrivacyContent`）。`generateMetadata` は `title`（「題名 | サイト名」）と `alternates: alternateUrls(lang, page)`（そのページの canonical と、同じページの3言語の hreflang）。ページは `src/i18n/lang.ts` の `PAGES`・`langPath(lang, page)` に集め、**`PAGES` に足したページは自動でプリキャッシュ（`scripts/service-worker.ts`。`PAGE_HTML_FILES`）と hreflang の対象になる**ので、管理用・下書き用のページは入れない。ページを足すときは、辞書・`PageFrame` の `page`・`Footer` のリンク・`PAGES` を合わせる。
  - 文は辞書（`ja.ts`・`en.ts`・`zh.ts`）の `about`・`privacy`（日本語はふりがなつき。こども向け・おとな向けの言い分けはしない）。URL（出典・Cloudflare の説明）は辞書に入れず `src/lib/sources.ts` の定数で、文は「前 + リンク + 後」（`LinkedSentence`）。節は `ContentSection`（`data-about-section`・`data-privacy-section`。`<section>` に名前を付けない）。改定日は `src/lib/site.ts` の `PRIVACY_REVISED_DATE`（内容を変えたら更新）。運営者のプロフィールと誤記・不具合の報告先は同じく `site.ts` の `OPERATOR_PROFILE_URL`・`PROJECT_ISSUES_URL` を使う（D47）。Web Analytics は T6-02 で入れる前提の文なので、入れない・集める項目が違うときは公開の前に `privacy` を直す。
  - E2E は `tests/e2e/pages.spec.ts`（フッターから開ける・出典の文・canonical と hreflang・言語切替・h1）、`a11y.spec.ts`（説明のページ）、`csp.spec.ts`、`pwa.spec.ts`（オフライン）。スクリーンショットは `ja-about`・`ja-privacy`・`en-about`。
