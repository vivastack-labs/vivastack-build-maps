# 実機確認のチェックリスト

対応環境（[開発概要書 5.3](development-overview.md)）のうち、CI（Playwright）では確かめられないものを、実際の端末で確かめる手順。

## 使い方

- 公開の前（T6-01）に、すべての項目を1回確かめる。その後は、画面・操作・PWA に関わる大きな変更のときに、該当する行だけを確かめる。
- 結果は「結果の記録」の表に書く。問題があれば、修正のタスクを作る。
- 前提：デプロイ（T0-06）が済んでいること。端末の実機から、HTTPS の URL（デプロイ後の本番か、プレビューの URL）で開く。PWA・オフライン・ホーム画面への追加の項目は、安全なコンテキスト（HTTPS）でないと Service Worker が動かないので、HTTPS の URL でしか確かめられない。`wrangler dev` を LAN の IP（`http://192.168…`）で開いても、Service Worker は登録されない。
- 確かめる前に、`https://jp-map.vivastack-dev.workers.dev/ja/` を、端末のブラウザの新しいタブ（シークレットでなくてよい）で開く。以前に開いたことのある端末では、Service Worker が古い内容を出すことがある。1〜2回再読み込みしてから確かめる。
- CI で確かめていること（確かめなくてよいこと）：3つのブラウザエンジンと、画面幅 360・768・1024・1366px での表示、すべてのページの横スクロール、マウス・キーボード・タップの操作、Pixel でのピンチ、オフラインの再読み込み（Chromium）、axe。プロジェクトの一覧は `playwright.config.ts`。

## 端末

Safari（macOS）・iOS・iPadOS は、最新と1つ前のメジャーバージョンで確かめる（Playwright は同梱の1つの版しか動かさないので、1つ前の版は実機だけで確かめる）。Chrome・Edge・Firefox は自動更新されるので、最新で確かめ、1つ前の版は `package.json` の `browserslist`（ビルドの対象）に任せて、個別には確かめない。

| 区分 | 端末・ブラウザ | 版 | 必ず確かめる点 |
|---|---|---|---|
| スマホ | iPhone の Safari | 最新・1つ前の iOS | 下の「全端末の共通の操作」、パネル、ピンチ・スワイプ、ホーム画面への追加、機内モード |
| スマホ | Android の Chrome | 最新 | 同上。WebAPK（ホーム画面への追加） |
| タブレット | iPad の Safari（縦・横） | 最新・1つ前の iPadOS（学校で管理されている iPad を含む） | 共通の操作、Apple Pencil、ピンチ・スワイプ、ホーム画面への追加 |
| タブレット | Android タブレットの Chrome（縦・横） | 最新 | 共通の操作、ピンチ・スワイプ |
| 学校の端末 | ChromeOS（Chromebook）の Chrome | 最新 | 共通の操作（タッチ画面があれば、タップも） |
| 学校の端末・PC | Windows の Edge | 最新 | 共通の操作、キーボード |
| PC | macOS の Safari | 最新・1つ前 | 共通の操作、キーボード |
| PC | Firefox・Chrome | 最新 | 共通の操作（CI で確かめているので、目で見て崩れがなければよい） |

## 全端末の共通の操作

- [ ] `/ja/`・`/en/`・`/zh/` が開く。言語の切替で、同じ県の選択（ハッシュ）が保たれる。
- [ ] モード（こども・おとな）とふりがなの切替が効き、開き直しても保たれる。
- [ ] 県をタップ（クリック）すると固定され、カードに行き方・名物・名所・出典が出る。もう一度タップすると解除される。
- [ ] 県の最大化（PC：ダブルクリック。タッチ：カードの「最大化」ボタン）で市区町村が出る。拡大・縮小・移動ができ、「全体」で戻る。
- [ ] さくいんの県名からも、同じように選べる。
- [ ] スマホ（768px 未満）：下から出るパネルが開閉でき、「くわしく」で広がり、地図・さくいん・フッターがパネルに隠れない。
- [ ] 出典のリンクが新しいタブで開く。選んでいた県の状態が元のタブに残っている。
- [ ] `#pref-13` のようなハッシュつきの URL を、別のタブや他のアプリ（メッセージなど）で開くと、その県が選ばれている。
- [ ] 横スクロールが出ない。文字が切れたり、重なったりしていない。

## CI で確かめられない項目

### タッチ・ペン

- [ ] iPhone・iPad（WebKit は CDP がなく、CI では確かめられない）：2本指のピンチで拡大・縮小でき、1本指のスワイプで動かせる。最大化中は、県の範囲の外へ動かせない。
- [ ] Apple Pencil（`pointerType` が `pen`）のダブルタップ：最大化と、Safari のダブルタップによるページの拡大が重ならない。
- [ ] 地図の上を縦にスワイプしても、ページがスクロールしない（`touch-action: none`）。地図の外に、スクロールできる余白（さくいん・地図の下など）があり、使いにくくない。

### ホーム画面への追加（PWA）

- [ ] iPhone の Safari・Android の Chrome で、ホーム画面に追加できる。アイコン・名前が正しく、開くとブラウザの枠がない（`standalone`）。
- [ ] 2つ以上の言語（例：ja と en）を追加したとき、それぞれの言語のページで開く（`start_url`）。
- [ ] Android：ホーム画面に追加した（WebAPK の）アプリがあるとき、外のリンク（メッセージなど）の `https://jp-map.vivastack-dev.workers.dev/…` を押すと、どのアプリで開くか。意図しない言語のアプリで開かないか（`scope` が3言語とも `/` で重なる）。
- [ ] Chrome の DevTools の Application で、Manifest にエラーや警告がなく、インストールできる（言語ごとの3つ）。

### オフライン・更新

- [ ] 一度開いた後に機内モードにして起動する。地図が出る。見たことのある県のカード・市区町村が出る。見ていない県は、オフラインの文（こどもモードは「インターネットにつながっていないので、表示できないよ」、おとなモードは「オフラインのため表示できません」。`src/i18n/ja.ts` の `offline`）と、再試行のボタン（こどもモードは「もう一度」、おとなモードは「再試行」）が出る。
- [ ] 説明のページ（このサイトについて・プライバシーポリシー）が、オフラインで開く。
- [ ] デプロイの後に、1〜2回の再読み込みで新しい内容になる。

### 学校の環境

- [ ] 学校で管理されている iPad（1つ前の iPadOS）で、地図・カード・パネルが動く。
- [ ] フィルタリングのある学校のネットワークで開ける（分かる範囲で。`jp-map.vivastack-dev.workers.dev`・`static.cloudflareinsights.com` がどちらも止められていないか）。

### 読み上げ

- [ ] iOS の VoiceOver（Safari）で、ふりがなが二重に読まれない。県の名前・カードの見出しが、ふりがなを含めずに1回だけ読まれる（T4-03 の確認を、スマホでもう一度）。
