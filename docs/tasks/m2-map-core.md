## T2-01 操作の状態遷移（mapReducer）

- **種別**：feat
- **依存関係**：T0-02
- **目的**：4.11 の操作仕様を、画面から切り離した純粋関数として実装する。すべての操作と状態の組み合わせを、テストで保証する。
- **参照仕様**：4.11.1、4.11.2、4.11.6、F-KB-05、F-ZOOM-04

### 実装内容

- `src/features/map/state.ts`：
  - 状態：`hovered`・`pinned`・`maximized` と、カードに表示する県（`displayed`）。拡大率と表示位置（`viewport`）は d3-zoom が持つので、ここでは扱わない（T2-06）。
  - 操作：ホバー、ホバーの終了、クリック、ダブルクリック、海・余白のクリック、Esc、全体表示、ハッシュからの復元（T3-07 で使う）。
  - `mapReducer(state, event)`：4.11.2 の表のとおりに新しい状態を返す。元の状態は変えない。
  - `cardPref(state)`：カードに表示する県を返す（`pinned` があればその県、なければ最後の `hovered`）。

### 完了条件

- `src/features/map/state.ts` のカバレッジが90%以上。
- 4.11.2 の表のすべてのセルに、対応するテストがある。

### テスト条件

- 単体（テスト名に「4.11.2 操作／状態」を入れる。例：`4.11.2 クリック／固定中・別の県：固定を移す`）：
  - 4.11.2 の表の各行（7つの操作）× 各列（通常・固定中・最大化中）。同じ県と別の県で結果が変わるセルは、両方を書く。
  - 不変条件：どんな操作の列の後でも、`maximized` が空でなければ `pinned` は同じ県である（4.11.1）。ランダムな操作の列で確かめる（fast-check などを使う）。
  - ダブルクリックの前に起きるクリック2回を含む列（クリック → クリック → ダブルクリック）の後は、「最大化＋固定」になる（4.11.2）。ただし、その県を最大化していない状態から始める。同じ県を最大化中のときは、ダブルクリックが「元に戻す」になり、最大化を解除して固定を残す（その列も確かめる）。
  - ホバーが終わっても、カードの県は残る。最初は空（案内を表示）（4.11.1）。
  - Esc：最大化中は最大化だけを解除し、固定中は固定を解除する（F-KB-05）。
  - 元の状態のオブジェクトを変えない。

## T2-06 拡大・縮小・移動

- **種別**：feat
- **依存関係**：T2-05
- **目的**：地図を拡大・縮小・移動でき、最大化した県に寄れるようにする。
- **参照仕様**：F-ZOOM-01〜05、4.11.2（`0`・`+` `-` の行）、4.11.3

### 実装内容

- `src/features/map/viewport.ts`（純粋関数）：範囲を表示領域に収める変換、倍率の上限・下限（最大化中の下限は県全体が収まる倍率）、ボタン1回分の倍率の変化。
- d3-zoom を地図の `<g>` に付ける：ホイール、ピンチ、ドラッグ・スワイプ。ダブルクリックでの拡大は無効にする。`<svg>` に `touch-action: none`（4.11.3）。
- 「＋」「−」「全体」のボタン（辞書の文言、`aria-label`）。
- 最大化したら県に寄り、解除したら全体表示に戻す。東京都に寄るときは、小笠原村まで範囲に入れると本土が小さくなる（T1-03）ので、範囲は父島（北緯28度より南）を除いた形の外接矩形にして、本土と伊豆諸島に寄る（U16、D36）。東京都のパスには父島が残っている（枠の下端に小さく見える）ので、範囲はパスの外接矩形ではなく、緯度で除いて求める。移動できる範囲の制限は、T2-08 が小笠原村を実際の位置に描くので、東京都では小笠原村まで動ける広さにする。（のちに D51 で、東京都は23区に寄り、本土と伊豆諸島は縮小の下限の範囲になった）
- `prefers-reduced-motion` のときは、動きの時間を0にする（F-ZOOM-05）。
- T2-05 で結線した状態を使う：最大化の状態（`maximized`）は `useMapState()`（`MapStateProvider` の Context）から読む。`MapInteraction` が地図の `<svg>` を包む `<div>` でクリックを受けているので、d3-zoom のドラッグの後に `click` が県に届いて固定が変わらないか確かめ、変わるなら d3-zoom の `clickDistance` などで区別する。E2E は `[data-map-ready]` を待ってから操作する。
- 確認項目：Apple Pencil（`pointerType` が `pen`）のダブルタップで、最大化と Safari のダブルタップ拡大が重ならないこと（`touch-action: none` で解消する想定）。

### 完了条件

- PC とスマホの両方で、拡大・縮小・移動ができる。

### テスト条件

- 単体（`viewport.ts`）：
  - 横長・縦長の範囲を、表示領域の中央に収める変換を返す。
  - 倍率は上限・下限を超えない。最大化中は、県全体が収まる倍率より小さくならない（4.11.2）。
- E2E：
  - 「＋」で倍率が上がり、「−」で下がる。ホイールでも変わる（F-ZOOM-01）。
  - 「全体」で倍率が1に戻る（F-ZOOM-02）。
  - 拡大した後、ドラッグで表示位置が変わる（F-ZOOM-03）。
  - 最大化すると、その県の範囲が表示領域いっぱいになる（F-ZOOM-04）。
  - `reducedMotion: 'reduce'` のとき、操作の直後に最終の位置になっている（F-ZOOM-05）。
  - ピンチは、Chromium でタッチの入力を再現できれば E2E に入れる。できなければ、実機確認のチェックリスト（T4-06）に入れる。

## T2-07 市区町村データの読み込み

- **種別**：feat
- **依存関係**：T2-06
- **目的**：県を最大化したときだけ市区町村データを読み込み、遅い・失敗した・オフラインのときでも操作が止まらないようにする。
- **参照仕様**：F-MUNI-05、4.11.5、5.1

### 実装内容

- `src/features/map/muniLoader.ts`：
  - `/geo/muni/NN.topo.json` を読み込み、メモリに残す（同じ県は2回読まない）。
  - 読み込んだデータの形を簡単に検証する。
  - 状態：読み込み中、300msを超えた、成功、失敗（通信エラー・404・形が不正）、オフライン。応答が15秒を超えたら打ち切って失敗にする（通信エラーと同じく、オフラインなら「オフライン」）。
  - 自動では再試行しない。
- 画面：最大化はすぐに行い、県の形だけを先に表示する。300msを超えたら「読み込み中」を `aria-live="polite"` で伝える。失敗したら文言と「再試行」ボタン。オフラインなら「オフラインのため表示できません」。

### 完了条件

- 4.11.5 の表の市区町村に関する3行が、すべて動く。

### テスト条件

- 単体（`muniLoader.ts`。fetch とタイマーを置き換える）：
  - 300ms以内に終わったら「読み込み中」にならない。300msを超えたらなる（4.11.5）。
  - 404・通信エラー・形が不正なデータは、それぞれ失敗になる。応答が15秒を超えたら失敗になる。
  - オフラインでの失敗は、オフラインの状態になる。
  - 同じ県の2回目は fetch しない。「再試行」で fetch し直す。
- E2E（Playwright の `page.route` で応答を変える）：
  - 応答を遅らせると「読み込み中」が表示され、`aria-live` の領域に入る。
  - 404 のとき、県の形で最大化したまま、失敗の文言と「再試行」が出る。「再試行」で成功すると、読み込みの状態が成功（`data-muni-status="loaded"`）になり、失敗の文言と「再試行」が消える。市区町村の形が描かれることの確認は、描くのが T2-08 なので、T2-08 の E2E に任せる。
  - 最大化は、読み込みの完了を待たずに行われる。

## T2-08 市区町村の描画

- **種別**：feat
- **依存関係**：T2-07
- **目的**：最大化した県の市区町村（政令指定都市は区）を描き、名前を確かめられるようにする。

### 実装内容

### T2-11 で決めたこと

- 結線は共通のフック `usePrefInteraction`（`src/components/`）。`MapInteraction`（地図）と `PrefIndexInteraction`（さくいん）が、ポインター・フォーカス＝ホバー・キー（Ctrl・Meta・Alt つきとキーの繰り返しは無視）・`data-*-ready`・`applyPrefState` の effect を共有する。違いはキーの処理（地図は矢印・Home・End・`+` `-` `0` を足す）と、さくいんの項目の外のクリックの扱いだけ。
- キーの規則は `keyboard.ts` の純粋関数。矢印は端（北海道・沖縄県）で止まる（回り込まない。Home・End で端へ飛べる）。最大化中も矢印で県を移れ、Shift + Enter で別の県に切り替えられる（マウスのダブルクリックと同じ）。`+` `-` `0` は `Shift` を見ない（`+` を Shift で打つ配列があるため）。
- Tab の停止位置は、サーバーの出力で北海道だけ `tabindex="0"`（ほかは `-1`）にし、クライアントが `rovingPref`（フォーカス中 → 固定中 → 北海道）の県に書き換える。地図の外にいる間は「固定中の県、なければ北海道」に戻る（矢印で青森県に移ってから Tab で出ると、次に Shift + Tab で入るのは北海道）。
- `+` `-` `0` は `MapZoom` の `MapZoomContext`（`useMapZoom()` が `{ step, reset }`。`MapZoom` の外では `null`）を通して、ボタンと同じ関数を呼ぶ。動きを減らす設定と、動きの途中の「＋」の目標の倍率がボタンと同じになる。
- Esc は地図・さくいんとも `escape`（最大化中は最大化の解除、なければ固定の解除）。ツールチップは、`Tooltip` が `document` の `keydown` で Esc を受けて隠す（フォーカスが地図の外でも、マウスが地図の上なら出ているため。WCAG 1.4.13）。
- フォーカスの枠は県のパスの `focus-visible:outline-solid`（太さは `calc(4px / var(--zoom-k, 1))`）。Chromium・Firefox・WebKit とも、県の外接矩形に枠が出る（後に描く隣の県に一部隠れるが、どの県かは分かる）。
- 「再試行」が成功してボタンが消えたら、押したときにフォーカスがボタンにあった場合だけ、最大化した県のパスにフォーカスを戻す（`MuniStatus`）。
- `[data-map-box]` を `overflow-hidden` から `overflow-clip` にした（スクロールできる箱にしない）。ただし、地図の `<svg>` は箱と同じ大きさで、層が外にはみ出しても `<svg>` で切られるため、`overflow-hidden` のままでも拡大中に画面の外の県へフォーカスして箱がスクロールすることは Chromium では起きなかった（E2E は両方で通る）。防御としての変更。
- フォーカスした県へ地図を自動で動かすことはしない（仕様にない。カードで県が分かり、`0` で全体に戻れる）。
