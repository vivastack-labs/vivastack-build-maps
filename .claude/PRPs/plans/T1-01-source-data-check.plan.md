## 調べ方

### 1. N03 の取得（`geo/downloads/`。コミットしない）

- `N03-20260101_GML.zip`（全国）を `curl` で取得する。zip の中身（GML・Shapefile・GeoJSON のどれがあるか）を `unzip -l` で見る。
- ダウンロードしたものは信頼しないデータとして扱う。展開は `geo/downloads/N03-2026/` だけで行い、調べるスクリプトはスクラッチパッドに置く。スクリプトは中身を読むだけで、実行はしない（Python は `-I`）。

### 2. 属性を調べる（U9・8.2）

Shapefile の `.dbf`（属性だけ）を Python の標準ライブラリで読む。文字コードは `.cpg` で確かめる。Shapefile がなければ GeoJSON を読む。次を数える。

- 全体の件数と、`N03_007` の重複のぐあい。島などで、1つの市区町村が複数の形に分かれている（T1-04 の手順1の前提）。
- 政令指定都市（20市）ごとに、`N03_005` がある形の、区の数と区コードの数。公表されている区の数（合計175区の見込み）と照らし合わせる。
- 政令指定都市の「市全体」の形（区のない行）があるか。あると、区と市が重なって二重に描かれる。
- 所属が決まっていない地域（`N03_004` が「所属未定地」など、またはコードが空）の件数・場所・属性の入り方。
- 都道府県の数（47）、市区町村コードの数。

### 3. 利用条件と入手先を調べる（U10・8.1）

公式のページを開いて確かめる。出典は、実際に開いて内容を確かめられた URL だけを書く（AGENTS.md）。

- **N03**：国土数値情報の利用規約、N03 の「使用許諾条件」。商用利用ができるか、出典の書き方（8.3 と合うか）。
- **全国地方公共団体コード（総務省）**：入手先（Excel）、カナの有無と形式（半角カナかどうか）、利用条件（政府標準利用規約 第2.0版なら CC BY 4.0 互換）、基準日。N03 のコードと突き合わせて、全部の市区町村・区にカナがあるか。
- **都道府県庁の位置**：国土地理院の「都道府県庁の経緯度」の公表値。入手先、測地系（世界測地系か）、利用条件（国土地理院コンテンツ利用規約）。
  → 実際には、国土地理院は一覧を公表していなかった（判断3と「承認後に変えたこと」）。

# 803,201,348 バイト。sha256 1f714fca019e22e6f84012dba420384fc7b49c6ad8bd0a867ab1cfb593a78477
unzip -l geo/downloads/N03-20260101_GML.zip

## 判断が必要な点

1. **取得するファイル**：推奨は全国の1ファイル（765.94MB）。
   - 理由：T1-04 も全国分から作る。県ごとに47回取得するより手順が単純。容量は手元に十分ある（空き 800GB 以上）。
   - 代わりの案：政令指定都市のある15道府県だけを取得する（速いが、所属が決まっていない地域や全体の件数を確かめられない）。
2. **調べるスクリプトをコミットするか**：推奨はコミットしない。コマンドと結果を PR と計画ファイルに書く。
   - 理由：このタスクの成果は「決めたこと」で、属性を読む処理は T1-04 の変換スクリプトがテスト付きで作る。今だけ使うスクリプトを残すと、テストのない保守の対象が増える。
3. **県庁の位置の出典**：推奨は国土地理院の公表値。利用条件に合わなければ、各都道府県の公表値を使う（開発計画 5章の推奨案）。
   - 理由：1つの出典で47県をそろえられる。距離は10km単位に丸めるので、出典による差は結果に出ない。
4. **カナの出典**：推奨は総務省の全国地方公共団体コード。N03 のコードと突き合わせて、足りない市区町村・区があれば、その一覧と対応（T1-04 で手で補う、など）を書く。
   - 理由：仕様（8.1）のとおり。
5. **調べた結果が仕様と違ったとき**：たとえば区が入っていない、市全体の形と区が重なっている、などの場合。代わりの方法を決めるタスクを開発計画に加え、その案を推奨案と理由を付けて確認する（開発計画 1.3）。
