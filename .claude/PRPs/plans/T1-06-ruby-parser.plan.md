## 方針

- `src/lib/ruby.ts` の中に、文字列を1回だけ走査する内部の関数 `scanRuby(text)` を置く。結果は「部分の配列」「文字の部分とその位置」「誤りの一覧」。
  - `parseRuby`：誤りがあれば例外を投げ、なければ部分の配列を返す。例外のメッセージは「N文字目：…」を「、」でつないだもの。N は書く人が数える字の数（𩸽 など BMP の外の字も1字）。
  - `checkRuby`：誤りの一覧と、文字の部分から探した警告（ふりがなの付いていない漢字）を返す。例外は投げない。
  - `plainText`：`parseRuby` の結果から、文字の部分とルビの親文字をつなげる（誤りがあれば例外）。
- 走査は正規表現の置換ではなく、1文字ずつ進める小さな状態機械にする（括弧の対応・位置を正確に出すため）。
  - 括弧の中で `{` が来たら誤りにし、外側の括弧を捨てて内側から読み直す。
  - 閉じ括弧のないまま終わったら、開き括弧の位置で「閉じ括弧がない」の誤りだけにする（中の `|` の数は見ない）。
  - 誤りのある括弧の中身は、部分にも警告の対象にも入れない。
- 返す値はすべて `readonly` の型にする。
- `src/components/RubyText.tsx` は `parseRuby` の結果を React の要素にするだけ。文字列は React が文字として出すので、`<script>` などはタグにならない。

### 型

```ts
export type RubySegment =
  | { readonly kind: 'text'; readonly text: string }
  | { readonly kind: 'ruby'; readonly base: string; readonly reading: string };

export type RubyIssue = {
  readonly index: number; // 文字列の中の位置（0始まり。UTF-16 の位置）
  readonly message: string; // 日本語。T1-07 がファイル名と項目の場所を前に付ける
};

export type RubyCheck = {
  readonly errors: readonly RubyIssue[];
  readonly warnings: readonly RubyIssue[];
};
```

## 判断が必要な点（承認済み）

| # | 項目 | 判断 | 理由 |
|---|---|---|---|
| 1 | 記法の誤りがある文を `parseRuby`（と `plainText`）に渡したとき | **例外を投げる**（位置を含むメッセージ）。誤りの一覧がほしいときは `checkRuby` を使う | ビルド時に変換するので、壊れた記法が `{北海道` のまま画面に出るより、ビルドが止まるほうが早く気付ける。コンテンツは T1-07 の検証で先に止まるので、ふつうはここまで来ない |
| 2 | 読みに使える字 | ひらがな（`ぁ`〜`ゖ`）と「ー」だけ。空白・ゝ・ゞ も誤り | 7.2 のとおり。ゝ・ゞ は今の教科書のふりがなでは使わない |
| 3 | 警告にする「漢字」の範囲 | Unicode の `Script=Han`（々・〆 を含む）。続いた漢字はまとめて1件 | 々 が付いた語（例：人々）も、ふりがながなければ小学生が読めない。1字ずつ出すと警告が多すぎて読みにくい |
| 4 | 仕様にない誤り | 対応しない `}`、括弧の中の `{`、括弧の中の `\|` が2つ以上、親文字が空（空白だけを含む）も誤りにする。括弧の外の `\|` はただの文字として扱う | どれも書き間違いで、変換すると壊れた表示になる。括弧の外の `\|` は英語・中国語の文で使われうるので、誤りにしない |
| 5 | `checkRuby` の言語 | 言語を受け取らない。日本語の文にだけ呼ぶのは T1-07 の役目にする | 中国語の文はすべて漢字なので、言語の判定を中に入れると、呼ぶ側との二重の管理になる |
| 6 | `RubyText` の形 | 包む要素を出さず、フラグメントで返す。`'use client'` もフックも使わない。`server-only` は付けない。`<rp>` も付けない | 包む要素は呼ぶ側で決めたい。UI文言の辞書（T2-02、D28）でもふりがなを使うので、クライアントコンポーネントからも使えるほうがよい。`server-only` は Vitest で読み込むと例外になる。対象のブラウザ（5.3）はすべて `<ruby>` に対応していて、`<rp>` はスクリーンリーダーで余分に読まれることがある（5.2） |
| 7 | `tests/unit/testing-library.test.tsx` | 消した | ファイルのコメントに「最初の本当のコンポーネントテストができたら消してよい」とある。`RubyText` のテストが同じことを確かめる |
