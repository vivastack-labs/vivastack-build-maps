# T4-03 アクセシビリティ：実装計画

- タスクの定義：`docs/tasks/m4-pwa-quality.md` の T4-03
- ブランチ：`test/T4-03-accessibility`
- 参照仕様：開発概要書 5.2、F-ZOOM-05、D26

## 目的

WCAG 2.2 AA を満たしていることを、自動の検査（axe・色の変数から計算するコントラスト）と、人の確認（スクリーンリーダー）で確かめる。

## 着手時に調べたこと

- `@axe-core/playwright` 4.14.0（2026-10-15 公開。Dependabot の cooldown の7日を過ぎている）を入れ、E2E のフィクスチャのビルドで、ja・en × ライト・ダーク × 最初の表示・固定中・最大化中を、chromium と iphone で試した（タグ `wcag2a`・`wcag2aa`・`wcag21a`・`wcag21aa`・`wcag22aa`）。
  - **違反は1種類だけ**：ja のページの「全体」ボタン（`button[data-zoom="reset"]`）の `label-content-name-mismatch`（WCAG 2.5.3）。`aria-label="全体"` に対して、見える文字が `<ruby>全体<rt>ぜんたい</rt></ruby>` なので、axe は「全体ぜんたい」が名前に含まれないと判断する。
  - incomplete（axe が判断できないもの）：SVG の中の文字（県名ラベル・海域名・市区町村のラベル）の `color-contrast`（「背景色が分からない」）。地図の上の「＋」「−」の `label-content-name-mismatch`（記号だけなので判断できない）。
- 小さな HTML で確かめたこと（chromium）：

  | 書き方 | axe | アクセシビリティツリーの名前 |
  |---|---|---|
  | `aria-label="全体"` ＋ `<rt>` | 違反 | 全体 |
  | `aria-label="全体"` ＋ `<rt aria-hidden="true">` | 違反（axe は見える文字に rt を含める） | 全体 |
  | `aria-label` なし ＋ `<rt>` | 通る | **全体 ぜんたい**（二重に読まれる） |
  | `aria-label` なし ＋ `<rt aria-hidden="true">` | 通る | 全体 |

  Chrome のアクセシビリティツリーでは、`<rt>` の読みが名前に入る（見出し・さくいんの県名・カードの文もすべて「北海道 ほっかいどう」になる）。5.2 の「ふりがなが二重に読み上げられないか」の問題は、少なくとも Chrome（＋ NVDA）では実際にある見込みが高い。
- 色の変数から計算したコントラスト（`app/globals.css`。県名ラベル `--color-map-label` と塗り）：
  - ライト：8地方 12.0〜15.3、固定中 `#fbbf24` 10.7、海域名 16.8、準備中の地 16.3・斜線 5.09、市区町村 12.3〜16.0、市区町村のホバー 7.9。
  - ダーク：8地方 6.8〜9.5、**固定中 `#d97706` と白いラベル `#f8fafc` は 3.04（4.5 に足りない）**、海域名 17.1、準備中 14.0・4.55、市区町村 6.8〜9.6、市区町村のホバー 4.95。

## 方針

### 1. axe の E2E（`tests/e2e/a11y.spec.ts`）

- 組み合わせ：3言語 × 2モード（`maps.mode` を `addInitScript` で localStorage に入れる）× ライト・ダーク（`page.emulateMedia({ colorScheme })`）。
- 状態：
  - PC（chromium のプロジェクトだけで動かす）：最初の表示・固定中（`#pref-01` から復元）・最大化中（カードの最大化ボタン。市区町村の一覧が出るまで待つ）。
  - スマホ（pixel のプロジェクトだけで動かす）：パネルを開いたとき（`peek`）・「くわしく」で広げたとき（`full`）。
  - ほかのプロジェクトでは飛ばす（同じ検査を7回くり返さない）。合計 3×2×2×5 = 60件。
- `AxeBuilder` のタグは `wcag2a`・`wcag2aa`・`wcag21a`・`wcag21aa`・`wcag22aa`。違反が1件でもあれば失敗し、メッセージに規則の ID と要素を出す。
- 除外（`exclude`・`disableRules`）はしない。
- CI：E2E は手動の `e2e.yml`（D30）なので、axe もそこで動く（5.2 の「CI で axe を実行し、違反があれば失敗させる」は、`e2e.yml` で満たす）。

### 2. 違反を直す（ふりがなの読み上げ）

- `RubyText` の `<rt>` に `aria-hidden="true"` を付ける（全体）。読み上げは本文の漢字だけになり、二重に読まれない（読みはスクリーンリーダーの音声合成に任せる）。見た目は変わらない。
- 「全体」ボタンの `aria-label` を外す（名前は見える文字の「全体」になる）。ほかの `aria-label={plainText(...)}`（「＋」「−」など、見える文字が記号のもの）は変えない。
- この対処は、下の「人の確認」の結果で決める（問題があれば変える）。開発概要書 5.2 に、確かめた結果と対処を書く。

### 3. コントラスト（色の変数から計算する単体テスト）

- `src/lib/contrast.ts`（純粋関数）：`contrastRatio(hex, hex)`（WCAG 2.x の相対輝度）。
- `tests/unit/styles/theme-contrast.test.ts`：`app/globals.css` の `@theme`（ライト）と `@media (prefers-color-scheme: dark)` の `:root`（ダーク）から `--color-*` を読み、次の組み合わせが 4.5:1 以上であることを確かめる（色の追加・変更で自動的に落ちる）。
  - 県名ラベル × 8地方・準備中の地・斜線、固定中の県のラベル × 固定中の塗り
  - 海域名 × 海
  - 市区町村のラベル × 市区町村の5色・ホバー
  - ツールチップの文字 × 背景、ページの文字 × 背景
- ダークの固定中の県のラベル：下の「判断が必要な点」1。

### 4. 人の確認（スクリーンリーダー）

- オーナーが、`pnpm build` ＋ `wrangler dev`（または PR のプレビューがあればそれ）で確かめる。手順と見るところを、PR の本文に書いて渡す：
  - VoiceOver（macOS Safari・iOS Safari）、NVDA（Windows Chrome または Firefox）。
  - ja のこどもモード・ふりがな ON で、見出し（サイト名・県名）、さくいんの県名ボタン、地図の県（`aria-label`）、カードの文、「全体」ボタンを読ませ、二重に読まれないか、漢字の読み間違いがひどくないかを見る。
- 結果を PR に書き、開発概要書 5.2 に「確かめた結果と対処」を書く。

### 5. 文書

- 開発概要書 5.2（axe の範囲と、ふりがなの読み上げの対処）、色を変えれば 6.2 の色の説明、更新日。
- `AGENTS.md`：アーキテクチャに「アクセシビリティの検査」（`a11y.spec.ts` の組み合わせ、コントラストの単体テスト、`<rt aria-hidden>` の決まり）。
- T4-06（対応環境の確認）に関係があれば書き足す。

## 承認後に変えたこと

- コントラストの単体テストに、計画にない組み合わせを足した：固定中の塗りの上の `text-slate-950`（切替のボタン・さくいんの項目）と、地図の県境・枠と海の 3:1（WCAG 1.4.11）。
- `RubyText` の `<rt aria-hidden>` に合わせて、既存の `RubyText.test.tsx`・`ModeText.test.tsx` の期待する HTML を直した（`getByRole` の name に読みを含めて探しているテストはなかった）。
- 開発概要書 5.2・6.2 と AGENTS.md に加え、タスクの定義（`docs/tasks/m4-pwa-quality.md`）にも実装したことを書いた。スクリーンリーダーの確認の結果は、メインが PR で確かめた後に 5.2 へ書き足す。
- レビューの指摘を直した：
  - 固定中の県名ラベルに、塗りと同じ色の縁取り（`stroke-map-selected`・`paint-order: stroke`・太さ `3px / --zoom-k`）を付けた（暗い文字が県の形からはみ出すと、海・地方の塗りの上で読めないため）。固定中のラベルと海・地方・準備中の地の比は検査せず、縁取り（塗り）との比と、ふつうのラベルと海の比を検査する。
  - 境界の線を 3:1 以上にした（WCAG 1.4.11）：`--color-map-border` のライト `#64748b` → `#5f6f86`・ダーク `#94a3b8` → `#f8fafc`、`--color-muni-border` のライト `#a8a29e` → `#5d5854`（ダークは変更なし）。
  - 色の読み取りを `src/lib/cssTheme.ts` に分け、読めない値・ダークの `@media` の重複を例外にした。
  - `a11y.spec.ts`：モード・配色が切り替わったことの確認、pixel の「パネルが閉じた最初の表示」（計72件）、最大化の待ちで倍率が1でなくなるのを先に確かめる、固定中のラベルの縁取りとホバーの確認（chromium）。
