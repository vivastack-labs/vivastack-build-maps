# T5-05 残りの県：富山県の制作計画

- タスクの定義：`docs/tasks/m5-content.md` の T5-05
- ブランチ：`feat/T5-05-content-toyama`（`develop` 向けの PR）
- PR のタイトル：`feat: add content for Toyama (T5-05)`
- 手順の見本：`.claude/PRPs/plans/T5-05-content-osaka.plan.md`（県ごとの計画は短くし、判断は PR の本文に書く）

## 目的

富山県（code 16、`content/prefectures/16-toyama.yaml`）の名物3・名所3・行き方を書いて、`verified` まで進める。`reviewed` にするのは、`develop` → `main` の PR のレビューの後（この PR ではしない）。

## 手順

1. スキル `gotouchi-content`（引数 `16`）の ①〜④ を、メインのセッションで動かす。
   - ① 下書き：出典のページを実際に開いて、おとな向けの日本語を書く。`pnpm content:furigana` でふりがなを付け、要確認の読みは公式の表記で確かめる。
   - ② 照合：`gotouchi-source-checker` で出典と事実を照合する（2回まで。誤りが残らないこと）。
   - ③ 派生版：こども向けの日本語・英語・中国語（簡体字）を作る。新しい事実を足さない。
   - ④ 検証：`gotouchi-derivative-checker` で派生版を検証する（2回まで）。
2. 検査：`pnpm content:validate`、`yamllint -c content/.yamllint`、`pnpm content:furigana --check`、`pnpm typecheck`、`pnpm vitest run --project data`。E2E は動かさない（データ整備の間は動かさない決まり）。
3. `develop` 向けに PR を出す（CI・プレビューは `develop` 向けでは動かない）。
