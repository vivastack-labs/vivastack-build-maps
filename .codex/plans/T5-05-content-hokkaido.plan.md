# T5-05 北海道のコンテンツ制作計画

- 対象：北海道の名物3件、名所3件、東京からの行き方。既存の県基本情報を維持する。
- 仕様：開発概要書 7.2・7.3・9.2・9.3、R8、執筆ルール。公式出典を実際に開き、成人向け日本語を確定してから派生版を作る。
- 推奨：出典と派生版の独立検証を通った項目のみ verified とし、人のレビュー後に reviewed とする。
- 変更：北海道 YAML と本計画。既存の検証器を使うデータ制作のため新規テストは追加せず、content:validate、ふりがな確認、lint、typecheck、test、build を実行する。
- 完了条件：各項目の出典照合、派生版検証、文字数・読み・スキーマの確認と、develop 向け県別 PR。reviewed はレビュー承認後にオーナーが判断する。
- 承認後に変えたこと：なし（作業前）。

## 制作・検証の記録

- 2026-11-18：AIRDO、JR北海道、農林水産省、北海道観光機構の各ページを開いて本文を確認。航空100分と快速最速37分の合算は乗り継ぎ待ちを含まない。
- 独立した出典照合：access・名物3件・函館山は通過。白金青い池は2回目に冬の景観の指摘を受けて修正し、再照合上限のため draft。知床五湖はレビュー後の3回目に森の映り込みが要確認となり、削除後の再照合ができないため draft。
- 派生版の独立検証：全項目が通過したが、知床五湖はその後の出典修正に伴い成人向け・翻訳を変更したため、改めて確認が必要。
- スキーマ検証は誤り・警告なし。ふりがな辞書の差分は味・函館山・白金・泥流の読みで、閉園は辞書にない。地名や泥流は公的資料等で確認。
- `pnpm typecheck`、`pnpm test`（2048件、制限外で再実行）、対象外 worktree を除いた ESLint、Prettier、変更計画の Markdown lint、コンテンツ YAML lint は通過。通常の `pnpm lint` は入れ子の worktree を走査し失敗。`pnpm build` はポート作成時の EPERM で制限外の再実行も失敗。
