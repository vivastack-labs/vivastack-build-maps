# T5-05 岐阜県のコンテンツ制作計画

## 対象と方針

- `content/prefectures/21-gifu.yaml` に名物3件、名所3件、東京から岐阜への行き方を制作する。県の基本情報は維持する。
- 名物は朴葉みそ・美濃和紙・さるぼぼ、名所は白川郷・飛騨高山の古い町並・岐阜城を候補とする。地域の多様な文化や場所を取り上げるための候補であり、公式資料と現在の状況を確認し、不適切なら差し替える。
- 東京からの経路は東海道新幹線と在来線を候補とし、交通機関の公式資料で区間・所要時間を確認する。乗換が必要な場合は区間の内訳と待ち時間の扱いを明記する。
- 開発概要書7.2・7.3・9.2〜9.4、執筆ルールとレビュー基準に従い、実際に開いた公式資料を優先する。

## 実施と確認

1. 大人向け日本語と出典を作り、ふりがなを確認する。出典照合役による独立検証と修正を行う。
2. 子ども向け日本語と英語・中国語の両モードを作り、派生版検証役による独立検証と修正を行う。両検証を通過した項目のみ `verified` にする。
3. 新規の単体テストは追加せず、既存の `pnpm content:validate`、`pnpm content:furigana --check content/prefectures/21-gifu.yaml`、`pnpm lint:yaml` でデータの形式・文字数・読みの候補を確認する。読みや事実の判断は機械検査に代えない。
4. `pnpm lint`・`pnpm typecheck`・`pnpm test`・`pnpm build` と独立レビューを行い、警告や未実施は理由を記録する。
5. 県ごとに `develop` 向け PR を作成する。レビュアーの承認とオーナーの判断を経て `reviewed` にし、マージする。T5-05 の状態は全県が完了するまで作業中とする。

## 判断

- 題材と交通手段は上記を推奨する。公式情報で裏付けられるものを優先し、季節や利用状況にも注意する。
- 県ごとの PR を推奨する。タスク定義と既存のデータ整備の運用に沿うため。

## 承認後に変えたこと

| 項目 | 承認時 | 実際 | 理由 |
|---|---|---|---|
| 名所の候補 | 岐阜城。公式情報で不適切なら差し替える方針 | 金華山に変更 | 岐阜城は改修工事で休館中で、再開は2027年11月予定。岐阜市の公式案内で確認した。 |

## 実施結果

- 東京10:30発ののぞみ25号で名古屋12:09着、12:48発のひだ11号で岐阜13:07着。所要157分には名古屋での乗換待ち39分を含む。JR西日本の時刻表を2026年11月20日に確認した。時刻表は改正時に再確認する。
- 出典の独立照合と派生版の独立検証を実施し、指摘を修正して7項目を `verified` にした。`reviewed` への変更は人によるレビュー後に行う。
- `pnpm content:validate` は誤り・警告0件。`pnpm content:furigana --check` の読みの差5件は、農林水産省・岐阜市などの表記と確認済みの富山県の内容で確認した。
- `pnpm lint`・`pnpm typecheck`・`pnpm test` は成功。テストは2048件、行カバレッジ96.94%。lint に既存の YAML 警告2件がある。
- `pnpm build` は実行環境で Turbopack のポート作成が許可されず失敗した。代替の `BUILD_TARGET=production pnpm exec next build --webpack` と `node scripts/postbuild.ts` は成功した。
- スクリーンショットは未取得。既存の撮影設定は固定のテスト用コンテンツを使うため今回の実データを表示できず、通常ビルドもこの環境では失敗する。実データを表示できる環境での確認が必要。
