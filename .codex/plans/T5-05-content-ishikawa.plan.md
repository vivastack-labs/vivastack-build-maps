# T5-05 石川県のコンテンツ制作計画

## 対象と方針

- 石川県の名物3件、名所3件、東京から金沢への行き方を制作する。県の基本情報は変更しない。
- 開発概要書7.2・7.3・9.2〜9.4、執筆ルール、レビュー基準に従う。事実の根拠は実際に開いた公式資料を優先する。
- 名物は治部煮・九谷焼・加賀友禅、名所は兼六園・金沢城公園・白山を候補とする。内容と利用状況を公式資料で確認し、不適切なら別の題材に替える。
- 東京からの行き方は北陸新幹線を候補とし、交通機関の公式時刻表で列車・時刻・所要時間を確認する。

## 手順と検証

1. `content/prefectures/17-ishikawa.yaml` の成人向け日本語と出典を作成し、ふりがなを付ける。出典照合役に独立検証を依頼し、指摘を修正する。
2. 子ども向け日本語と英語・中国語の両モードを作成し、派生版検証役に独立検証を依頼する。両検証を通過した項目だけ `verified` にする。
3. データ変更のため新規の単体テストは設けず、既存の `pnpm content:validate`、`pnpm content:furigana --check content/prefectures/17-ishikawa.yaml`、`pnpm lint:yaml` で形式・文字数・読みの候補を確認する。読みや事実は機械検査だけで通過としない。
4. `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build` と独立レビューを実施し、失敗や警告は理由とともに記録する。県別 PR は `develop` 向けとする。
5. レビュアーによる承認とオーナーの判断を受けてから `reviewed` とし、マージする。T5-05 全体は残り5県が完了するまで作業中とする。

## 判断

- 題材は県の多様な文化と場所を紹介できる組み合わせを推奨する。出典や現在の公開状況を確かめた上で最終決定する。
- 県ごとの PR を推奨する。タスク定義と既存のデータ整備の運用に従えるため。
- 既存の `develop` リモートブランチは削除済みのため、PR の土台として現在の `main` と同じコミットから再作成する。
