# T5-05 山梨県のコンテンツ制作計画

## 対象と方針

- `content/prefectures/19-yamanashi.yaml` に名物3件、名所3件、東京から甲府への行き方を制作する。県の基本情報は維持する。
- 名物はほうとう・甲州印伝・ぶどう、名所は昇仙峡・河口湖・武田神社を候補とする。地域の多様な文化や場所を取り上げるための候補であり、公式資料と現在の状況を確認し、不適切なら差し替える。
- 東京からの経路は中央線特急を候補とし、交通機関の公式資料で区間・所要時間を確認する。乗換が必要な場合は区間の内訳と待ち時間の扱いを明記する。
- 開発概要書7.2・7.3・9.2〜9.4、執筆ルールとレビュー基準に従い、実際に開いた公式資料を優先する。

## 実施と確認

1. 大人向け日本語と出典を作り、ふりがなを確認する。出典照合役による独立検証と修正を行う。
2. 子ども向け日本語と英語・中国語の両モードを作り、派生版検証役による独立検証と修正を行う。両検証を通過した項目のみ `verified` にする。
3. 新規の単体テストは追加せず、既存の `pnpm content:validate`、`pnpm content:furigana --check content/prefectures/19-yamanashi.yaml`、`pnpm lint:yaml` でデータの形式・文字数・読みの候補を確認する。読みや事実の判断は機械検査に代えない。
4. `pnpm lint`・`pnpm typecheck`・`pnpm test`・`pnpm build` と独立レビューを行い、警告や未実施は理由を記録する。
5. 県ごとに `develop` 向け PR を作成する。レビュアーの承認とオーナーの判断を経て `reviewed` にし、マージする。T5-05 の状態は全県が完了するまで作業中とする。

## 判断

- 題材と交通手段は上記を推奨する。公式情報で裏付けられるものを優先し、季節や利用状況にも注意する。
- 県ごとの PR を推奨する。タスク定義と既存のデータ整備の運用に沿うため。
