# T5-05 群馬県の制作計画

- 群馬県の名物3件・名所3件・東京からの行き方を制作し、県の基本情報は維持する。
- 開発概要書7.2・7.3・9.2・9.3と執筆ルールに従い、公式資料を開いて成人向け日本語を作り、出典照合後に派生版を仕上げる。
- 出典・派生版の独立検証を行い、両方通過した項目のみ verified とする。未確認は draft、人のレビュー後に reviewed とする。
- 新規テストは追加せず、既存の content:validate、ふりがな、YAML lint、型検査、テスト、ビルドと独立レビューで確認する。
- develop 向け県別 PR を作り、未確認事項を記録する。T5-05 全体は作業中のままとする。

## 実施記録

- 2026-11-19 08:40〜08:49：農林水産省、富岡市、群馬県、沼田市観光協会、JR東日本の資料を開いて7項目を制作した。とき315号の東京10:15発・高崎11:03着は48分。ダイヤは年1回見直す。
- 出典照合初回は誤り3件・要確認2件、2回目はおっきりこみ・こんにゃく味噌おでんの文章類似と吹割の滝の冬季閉鎖の確認に誤り3件。修正後は上限に達したため3項目を draft、残り4項目は出典・派生版を通過し verified。滝の閉鎖はメインが実際に開いた観光協会の見学欄で確認したが、出典検証役の環境では確認できなかった。
- 派生版初回の誤り3件・要確認1件を修正し、2回目に通過。レビューで吹割の滝の冬季閉鎖が冬全体と読める点を修正、同項目は draft に留める。湯畑・湯樋の読みは文化庁、吹割の読みは沼田市観光協会で確認した。
- content:validate・対象 YAML lint・typecheck・全テスト2048件は通過、行カバレッジ96.94%。データ検査177件も通過。通常の build はポート作成時の EPERM で失敗したが、同じ本番設定で webpack の build と postbuild は成功。全体 lint は直前の県で入れ子の worktree まで走査し既存の大量エラーで失敗、対象 YAML の lint は通過。
